# @kirejs/i18n

`@kirejs/i18n` adds Laravel-style localization to Kire templates.

## What it adds

- `@lang("key", replacements?)` directive
- `@choice("key", count, replacements?)` directive (pluralization)
- global helpers `__(key, replacements?)`, `trans(...)`, and `trans_choice(key, count, replacements?)`

## Setup

```ts
import { Kire } from "kire";
import { KireI18n } from "@kirejs/i18n";

const kire = new Kire();

kire.plugin(KireI18n, {
  locale: "pt",
  fallback: "en",
  translations: {
    pt: {
      messages: {
        welcome: "Olá, :name!",
        items: "{0} nenhum item|{1} um item|[2,*] :count itens",
      },
    },
    en: {
      messages: { welcome: "Hello, :name!" },
    },
  },
});
```

Keys may be dotted (`messages.welcome`) and resolve through nested translation trees. A missing key falls back to `fallback`, then returns the key itself.

## Placeholders

Use `:name` (or `{name}`) placeholders, filled from the replacements object:

```kire
@lang("messages.welcome", { name: user.name })
{{ __("messages.welcome", { name: user.name }) }}
```

Output is HTML-escaped by `@lang`.

## Pluralization

`@choice` (and `trans_choice`) select a segment by `count`. Segments are separated by `|` and may carry conditions; `:count` is available in replacements.

```
{0} nenhum item|{1} um item|[2,*] :count itens
```

```kire
@choice("messages.items", cart.length)
```

- `{n}` matches an exact count.
- `[a,b]` / `[a,*]` match an inclusive range.
- Without conditions, two segments are treated as `singular|plural`.

## Helpers

```kire
{{ __("messages.welcome", { name: "Ana" }) }}
{{ trans_choice("messages.items", 3) }}
```
